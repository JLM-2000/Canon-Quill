# Writing Rubric

## Core Standard

The book must sound like the user or approved reference style, not like generic AI prose.

## Preparation Gates

- Project brief exists.
- Book/series status is clear.
- Plot, character, world, and style artifacts exist.
- Missing reference information is explicitly marked.
- User has approved the starting point.

## Chapter Drafting

- Follow approved plot and chapter purpose.
- Preserve POV, tense, distance, and tone.
- Use character-specific action, thought, and dialogue.
- Keep mysteries open or explained according to policy.
- Follow intimacy/spice boundary.

## Editing

- Remove empty lyricism.
- Replace vague emotion labels with evidence where useful.
- Remove AI-isms and repeated templates.
- Tighten exposition.
- Preserve voice, not sterile correctness.

## Validation

- Canon consistency.
- Plot causality.
- Character physicality and knowledge consistency.
- Dialogue voice separation.
- Target audience suitability.
- Proofread quality.
